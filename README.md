# Домашка 10_2
## Краткое описание
Домашняя работа выполнена в продолжение работы 9_1, 9_2 и 10.1 по созданию виджета банковских операций.
Ветка main и develop содержат результаты предыдущей работы, а именно: toml-файл, gitignore, модуль main, модули masks и widget.
В ветке feature/Homework_10_1 закоммичен модуль src/processing, ждет проверки через pull request.
В ветке feature/homework_tests реализованы тесты ко всем модулям пакета src/ с использованием фикстур и параметризации.<br>
Результаты тестирования приведены в директории htmlcov, исключенной из .gitignore.


## Установка и использование
### Требования:
Python 3.14<br>
Poetry 2.3.2
### Установка проекта
Клонируйте репозиторий<br>
git clone git@github.com:AlexValenko/Valenko_mod2_Homework10_1.git<br>
Установите poetry<br>
pip install poetry<br>
Установите зависимости<br>
poetry install

### Зависимости
В проекте отсутствуют внешние зависимости.<br>
Все необходимые настройки находятся в pyproject.toml.<br>

flake8 — проверка стиля кода<br>
black — автоформатирование кода<br>
isort — сортировка импортов<br>
mypy — статическая типизация<br>

## Примеры использования
### Описание функций
В main.py реализованы функции (модуль src.masks)<br>
Маскировки номера карты get_mask_card_number():<br>
ввод: 7000792289606361<br>
вывод: Маскированный номер карты: 7000 79** **** 6361<br>

Функция маскировки номера счета get_mask_account():<br>
ввод: 73654108430135874305<br>
Вывод: Маскированный номер счета: **4305<br>

В модуле widget реализована функция mask_account_card, позволяющая вернуть замаскированный номер счета или карты в зависимости от ввода.<br>
В модуле widget функция get_date возвращает дату в формате ДД.ММ.ГГГГ из формата ISO<br>

В модуле processing функция filter_by_state возвращает новый список словарей, содержащий только те словари, у которых ключ state соответствует указанному значению<br>
В модуле processing функция sort_by_date возвращает новый список, отсортированный по дате
