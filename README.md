# Виджет банковских операций
## Краткое описание
Проект содержит домашние работы 9.1, 9.2, 10.1, 10.2, 11.1, 11.2, 12.1, 12.2, 13.1, 13.2 по созданию виджета банковских операций.<br>
Основные ветки проекта main и develop. Функциональный код содержится в пакете /src, тестирование в /tests. Логи по результатам тестирования функций записываются в <PROJECT>/logs/mylog.txt.<br>
Директория /logs включена в .gitignore<br>
Проект выполнен в IDE PyCharm с использованием Poetry. Зависимости прописаны в toml-файле.<br>
Результаты тестирования приведены в директории htmlcov, исключенной из .gitignore.

## Примеры использования
### Описание функций
Функционал основного модуля main.py реализован приложения с пользовательским вводом и выводом в консоль.<br>
Программа последовательно выполняет следующие действия:<br>
+ Предлагает выбрать исходный файл с транзакциями в форматах json/csv/xlsx на выбор.<br>
+ Предлагает выбрать статус операций, после чего фильтрует все транзакции по выбранному статусу<br>
+ После фильтрации программа выводит вопросы для уточнения выборки операций, необходимых пользователю:<br>
- Применить сортировку по дате, по возрастанию или убыванию, <br>
- Выводить ли только рублевые транзакции или транзакции в любой валюте, <br>
- Отфильтровать ли список транзакций по определенному слову в описании <br>

После ввода данных, программа выводит в консоль список банковских транзакций с учетом вышеперечисленных фильтров и сортировок.<br>
Транзакции выводятся в стандартизированном виде с маскировкой номеров карты и счета, приведением даты к формату ДД.ММ.ГГГГ, а также описанием транзакции и суммой.<br>
*18.07.2018 Перевод организации* <br>
*Visa Platinum 7492 65*** **** *7202 -> Счет* ***0034<br>
Сумма: 8390 руб.<br>*

Основные рабочие функции расположены в модулях пакета /src <br>
**Модуль masks<br>**
Функция get_mask_card_number() - маскирует номер банковской карты по шаблону 7000792289606361 -> 7000 79** **** 6361 <br>
Функция get_mask_account() - маскирует номера счета (ввод: 73654108430135874305 --> Вывод: Маскированный номер счета: **4305<br>
Для реализованных функций предусмотрено логирование в файл logs/log_masks.log<br>
**Модуль widget<br>**
В модуле widget реализована функция mask_account_card, позволяющая вернуть замаскированный номер счета или карты в зависимости от ввода.<br>
В модуле widget функция get_date возвращает дату в формате ДД.ММ.ГГГГ из формата ISO<br>
**Модуль processing<br>**
В модуле processing функция filter_by_state возвращает новый список словарей, содержащий только те словари, у которых ключ state соответствует указанному значению<br>
В модуле processing функция sort_by_date возвращает новый список, отсортированный по дате<br>
**Модуль generators<br>**
filter_by_currency - генераторная функция, принимает на вход список словарей, представляющих транзакции.
и Функция возвращает значения итератора (yield from), который поочередно выдает транзакции, где валюта операции соответствует заданной, например 'USD'<br>
transaction_descriptions - генераторная функция, принимает на вход список словарей, представляющих транзакции. Возвращает описание каждой операции в порядке их перечисления в списке. <br>
card_number_generator - генераторная функция, принимает начальный и конечные номера диапазона и генерирует номера банковских карт формата XXXX XXXX XXXX XXXX в заданном диапазоне. <br>
**Модуль decorators<br>**
В модуле реализован декоратор логирования вызова функций. Декоратор с параметром принимает на вход путь к лог-файлу (При тестировании использован путь/<PROJECT>/logs/mylog.txt).
Пример записи в лог-файл при успешной работе функции: *foo "example_foo" started at 2026-04-22 11:28:43 inputs: (3, 4), {}, result: 7, work_time = 0.0000067 sec*
В случае, если декоратору не задан параметр (путь), логи в упрощенном виде выводятся в консоль, например *example_foo OK*<br>
**Модуль utils<br>**
get_fin_transactions() - функция принимает на вход путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях. 
В функции обработаны исключения FileNotFoundError, JSONDecodeError. Если файл пустой, содержит не список или не найден, функция выведет соответствующее сообщение в консоль и вернет пустой список.<br>
Для реализованных функций предусмотрено логирование в файл logs/log_utils.log<br>
**Модуль external_api<br>**
get_amount_transaction_rub() - функция которая принимает на вход транзакцию (тип данных - dict) и возвращает сумму транзакции (amount) в рублях, тип данных — float. 
Если транзакция была в USD или EUR выполняется вызов функции get_amount_rub() из того же модуля, в которой, происходит обращение к внешнему API 
для получения текущего курса валют и конвертации суммы операции в рубли. Для конвертации валюты используется Exchange Rates Data API: https://apilayer.com/exchangerates_data-api.
запрос обрабатывается в функции get_amount_rub() и возвращается в get_amount_transaction_rub(), преобразовывается во float и округляется до 0.01 руб. 
В функциях реализована обработка исключений, в случае неудачного подключения или иных проблем, указанные функции возвращают None.<br>
**Модуль read_csv_excel<br>**
В модуле реализованы функции get_transaction_from_csv и get_transaction_from_excel, которые реализуют считывания финансовых операций из файлов .csv и .xlsx соответственно.
На входе указанные функции принимают путь к файлу с соответствующим расширением. Функции возвращают список словарей с финансовыми транзакциями. В функциях обработаны исключения FileNotFoundError, 
а также реализована проверка на соответствие заголовков столбцов и ожидаемых ключей словаря *{"id", "state", "date", "amount", "currency_name", "currency_code", "from", "to", "description"}*.
При помощи вспомогательной функции get_standard_transactions в данных исключаются пустые строки, словарь приводится ко стандартному виду (добавлена вложенность).<br>
**Модуль search<br>**
В модуле реализованы функции:
process_bank_search - осуществляет поиск в списке банковских операций по описанию операции. Применяет библиотеку re.<br>
process_bank_operations - принимает список словарей с данными о банковских операциях и список категорий операций, возвращает словарь, в котором ключи — это названия категорий, а значения — это количество операций в каждой категории.<br>
